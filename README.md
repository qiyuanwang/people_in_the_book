# 书中人｜文学人格身份证 FINAL v7.0

这是用于 GitHub Pages 的最终静态网站成品。正式用户入口是 `index.html`；`preview.html` 仅供卖家质检，不在正式产品里展示入口。

## 产品体验

- 20 道主测题，约 3–5 分钟。
- 必要时自动追加 5 道澄清题；答卷区分度仍不足时，不强行分配角色。
- O / C / E / A / S 五个连续人格维度，每维 4 道题，正反向各 2 道。
- 24 个经典文学角色人格原型；显示主型 + 副型，而不是随机抽取。
- 每个结果包含 4 页可收藏视觉档案、五维星图、第一句自我确认、约 3700–4000 字深度档案、分享身份证。
- 正式结果页不再暴露“全部角色图鉴”，保持个人结果的专属感。
- 答题数据仅保存在用户浏览器本地，不上传服务器。

## 发布到 GitHub Pages

1. 新建 GitHub 仓库。
2. 解压最终 ZIP，把**里面所有文件**上传到仓库根目录；不要只上传 ZIP，也不要再套一层文件夹。
3. 打开 `Settings → Pages`。
4. `Build and deployment` 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/ (root)`，保存。
6. GitHub 给出公开网址后，用手机和电脑各测试一次。

## 卖家质检入口（不要主动发给买家）

访问：`你的网址/preview.html`

可以直接查看 24 种角色，不用重复答题。

## 上线前建议自己测试 3 次

1. 按真实状态正常作答，确认题目、补测、结果揭晓和滑图顺畅。
2. 故意 20 题全部选“一半一半”，确认系统不会随便给角色，而会要求补测/重测。
3. 在手机浏览器测试“生成分享身份证”和“复制分享文案”。

## 心理学与宣传边界

本产品底层采用五个连续人格维度与正反向题结构，并用角色原型向量做文学化映射；这比随机趣味测试更有内部逻辑和可重复性。

但当前 20 道中文题及 24 个文学角色映射**尚未经过正式大样本常模验证**。因此适合宣传为：

> “基于五维人格结构设计的文学人格自我探索测试”

不要宣传为：

- “心理学权威认证”
- “临床测试”
- “准确率 95% / 99%”
- “比专业人格量表更准”

正式运营后，可用真实匿名样本检查内部一致性、重测稳定性和 24 角色命中分布，再迭代原型向量。

## 文件说明

- `index.html`：正式用户入口
- `style.css`：全部视觉样式
- `app.js`：答题、计分、补测、结果、分享逻辑
- `data.js`：20 题、5 道补测、24 角色数据与完整文案
- `assets/results/01~24/`：24 × 4 = 96 张结果视觉页
- `assets/ui/cover_v2.webp`：正式首页背景
- `preview.html`：卖家内部质检页
- `source/`：母稿与计分配置备份
- `FINAL_QA.md`：最终自动核查结果

## 商业提醒

GitHub Pages 是公开静态网址。若买家把网址转发给别人，对方也能访问。前期用来验证“5 元是否有人买”很合适；销量稳定后，如需一单一码或付费后解锁，需要增加服务端鉴权。
